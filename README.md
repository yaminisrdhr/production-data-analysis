# Production Data Analysis

## 📌 Project Overview

This project analyzes weekly production data using Python.

The objective is to practice Python data-processing techniques while applying them to a simple manufacturing scenario.

## 🎯 Analysis Performed

The project calculates:

- Total production
- Average daily production
- Maximum production
- Minimum production
- Production range
- Days with production above 130 units
- Production values converted into hundreds
- Production values sorted in ascending and descending order

## 🛠️ Python Concepts Used

- Lists
- `sum()`
- `max()` and `min()`
- `len()`
- `round()`
- `zip()`
- `filter()`
- `map()`
- `sorted()`
- Lambda functions

## 🏭 Manufacturing Context

Production data can be used to identify variations in daily output and understand production performance.

For this dataset:

- **Total production:** 920 units
- **Average daily production:** 131.43 units
- **Maximum production:** 160 units
- **Minimum production:** 98 units
- **Production range:** 62 units

Production above 130 units was also identified to highlight higher-performing production days.
